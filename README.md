# Algorithmic Art Skill

A Claude skill for creating original generative art through algorithmic philosophies and p5.js implementations.

## What it does

This skill guides Claude through developing a generative-art concept, defining its computational philosophy, and expressing that philosophy as an interactive, seed-driven p5.js artwork. It emphasizes reproducibility, carefully tuned parameters, emergent behavior, and a self-contained HTML artifact.

## Repository contents

- `SKILL.md`: Main skill instructions and workflow.
- `templates/generator_template.js`: Reference structure and patterns for p5.js generative algorithms.
- `templates/viewer.html`: Interactive viewer template with controls for seeds and parameters.
- `LICENSE.txt`: Original component license file.

## Use

Place this skill in the skills directory supported by your Claude environment, keeping the directory structure intact. The instructions in `SKILL.md` explain how to use the templates when generating artwork.
