# Generative Artwork Quality Review

## Concept and composition
- [ ] The algorithm expresses the written philosophy.
- [ ] The composition has hierarchy, balance, and intentional negative space.
- [ ] Complexity supports the idea instead of becoming visual noise.
- [ ] Color relationships are deliberate and accessible.
- [ ] The result is original rather than imitating a specific artist.

## Algorithm and implementation
- [ ] Seeded randomness is deterministic.
- [ ] Parameters have meaningful, understandable effects.
- [ ] Defaults produce a strong result without manual adjustment.
- [ ] Degenerate values and edge cases are handled.
- [ ] Static and animated modes behave as intended.
- [ ] Rendering work is bounded and performant.

## Viewer and export
- [ ] The supplied viewer template's fixed structure is preserved.
- [ ] Seed navigation and parameter controls work.
- [ ] Regenerate and reset behavior are correct.
- [ ] PNG export has the expected dimensions and quality.
- [ ] The artifact works in the target browser without undocumented setup.
